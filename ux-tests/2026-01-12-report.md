## Blockers (stop users completely)

### 1. [BLOCKER] Init command hangs on interactive prompts without TTY
- **Error message**: `Warning: Detected unsettled top-level await at file:///Users/jorgevidaurre/agents-squads/squads-cli/dist/cli.js:12949`
- **What happened**: When running `squads init` in non-interactive mode (no TTY), the command hangs at:
  1. "Set up local infrastructure (postgres, redis)? [Y/n]"
  2. "Get product updates? (optional, Enter to skip)"
- **Expected**: Non-interactive mode should use defaults or exit gracefully
- **Impact**: Critical - CI/CD pipelines, scripts, and automation cannot use init
- **Suggested fix**:
  - Detect non-TTY environment and use defaults
  - Add `--yes` flag to accept all defaults
  - Add `--no-email` flag to skip email prompt

## Friction Points (slow users down)

### 1. [FRICTION] Claude CLI login warning during init
- **What happened**: Init shows "Installed but may need login" warning even when Claude is installed
- **Suggested fix**: Only show warning if Claude login actually fails, or check auth status properly
- **Impact**: Low - just informational noise

### 2. [FRICTION] Email prompt at end of init feels intrusive
- **What happened**: After successful init, user is prompted for email for product updates
- **Suggested fix**: Make this optional via a flag, or move to a separate command
- **Impact**: Medium - breaks flow, feels like marketing capture

### 3. [FRICTION] Help text doesn't show examples for main commands
- **What happened**: `squads --help` shows commands but no quick examples
- **Suggested fix**: Add 2-3 common workflow examples at the bottom of help
- **Impact**: Low - users can find examples in subcommand help
